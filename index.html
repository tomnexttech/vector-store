VECTOR GATE

Apache-2.0

A permission hook that sits in front of every Claude Code tool call. No LLM in the loop: plain Python, standard library only, so the rules are short enough to read and argue with. Every decision is appended to a log where each line carries the SHA-256 of the line before it.

DenyReading secrets, formatting a disk, writing the registry, changing the gate itself
AskDeleting, git push, overwriting with >, sending data off the machine
SilentEverything else. Silence never approves anything.

FAQ

Do I need a plugin?

No. Drag a PNG or a clip onto a track above your footage. There is no project file and no plugin, and the FUI Pack is not an After Effects template.

GLOW or ADD?

Use GLOW with the normal blend mode. Use ADD with Add or Screen. For an intro, put boot first and loop right after it.

Can I use it for client work?

Yes. You may deliver the finished work to your client. If your client needs the source files themselves, the client buys their own license.

Does the UI Kit need a framework?

No. It is plain HTML, CSS and a small dependency-free script. No fonts are bundled. It uses Bahnschrift or DIN where available and falls back to system-ui.

Do I need Claude Code for VECTOR DECK?

Yes. You install Claude Code yourself, from Anthropic. VECTOR DECK does not sell or bundle it, and it is not for sale yet.
