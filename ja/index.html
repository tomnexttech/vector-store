VECTOR GATE

オープンソース（Apache-2.0）

無料

Claude Code がツールを呼び出すたびに、その手前で可否を判定するフックです。LLM は使わず、標準ライブラリだけの Python で書いているので、規則は読んで確かめられる短さに収まっています。判定はすべてログに追記され、各行が直前の行の SHA-256 を持ちます。

Deny秘密情報の読み取り、ディスクの初期化、レジストリへの書き込み、ゲート自体の変更
Ask削除、git push、> による上書き、PC の外へのデータ送信
Silentそれ以外。ゲートが黙っていても、許可したことにはなりません。

D

使用許諾とよくある質問

動画・配信・ゲームなど、完成した作品の中でお使いいただけます。素材そのものの再配布・転売はできません。詳しくは各商品ページをご覧ください。

プラグインは必要ですか

必要ありません。PNG や動画を、映像の上のトラックに置くだけです。プロジェクトファイルもプラグインも不要で、FUI Pack は After Effects のテンプレートではありません。

受託の仕事に使えますか

使えます。完成した作品を依頼主へ納品できます。依頼主が素材ファイルそのものを必要とする場合は、依頼主ご自身で使用許諾をご購入ください。

UI キットにフレームワークは必要ですか

必要ありません。HTML と CSS と、依存のない小さなスクリプトだけです。フォントは同梱していません。Bahnschrift か DIN があればそれを、なければ system-ui を使います。

Field Notes は日本語で読めますか

いいえ、英語版のみです。
